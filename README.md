#CinéTrack

A simple web app to search movies and series, view details, and save your favorites.

#Features

- Search by title and filter by Movies or Series
- View movie/series details in a popup modal
- Save and manage favorites using localStorage
- Paginated grid layout

#Built With

- HTML5 & Tailwind CSS
- Vanilla JavaScript (ES6 Modules)

#How to Run

- Clone or download the project.
- Open the folder in VS Code and run index.html using Live Server.
